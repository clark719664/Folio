Goal — ship a beautiful free open-source PDF editor with the complete requested Acrobat feature coverage in its first release. The tasks below establish its foundation and must be extended to cover the full inventory before release.

Architecture — React and TypeScript interface with local PDF processing through an open-source engine. Keep document state and export operations distinct from rendering.

- Every implemented feature is free.
- All application source and dependency license information are available.

- UI words provide navigation, actions or necessary feedback.
- Full Acrobat parity is a first-release requirement. All pending capabilities block release.

- [ ] Establish app, dependency licenses and engine integration. Verify rendering a real PDF.
- [ ] Implement document opening, navigation, zoom and text selection/search with correct rotated-page geometry.
- [ ] Implement actual content correction and export. Verify old text removed and replacement extractable after reopening.

## Review focus

Preserve untouched PDF content. Handle unavailable fonts explicitly. Protect state when loading fails or another file opens. Match edit geometry to page rotation and zoom. Export user edits successfully and report errors. Check dependencies and saved PDF content independently of on-screen appearance.
